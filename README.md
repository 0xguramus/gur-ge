# gur.ge — პირადი ბლოგი

ბლოგი აწყობილია [Astro](https://astro.build)-ზე. ჩანაწერები ჩვეულებრივი Markdown (`.md`) ფაილებია.

## როგორ დავამატო ახალი ჩანაწერი

1. გახსენი საქაღალდე `src/content/posts/`.
2. შექმენი ახალი ფაილი, მაგალითად `pirveli-chanaceri.md`. ფაილის სახელი ლათინური ასოებით დაწერე, რადგან ის ბმულის ნაწილი იქნება: `gur.ge/posts/pirveli-chanaceri/`.
3. ფაილის თავში ჩაწერე ეს ბლოკი და შეავსე:

```markdown
---
title: "ჩანაწერის სათაური"
description: "ერთი-ორი წინადადება, რომელიც მთავარ გვერდზე გამოჩნდება"
date: 2026-10-20
category: psychology
---

აქ დაწერე ჩანაწერის ტექსტი.
```

4. `category` ველში ჩაწერე ერთ-ერთი:
   - `psychology` — ფსიქოლოგია
   - `health` — ჯანსაღი ცხოვრება
   - `business` — ბიზნესი და მარკეტინგი
   - `notes` — ჩანაწერები
5. თუ ჩანაწერი ჯერ არ გინდა გამოაქვეყნო, დაამატე სტრიქონი `draft: true`.

სანიმუშო ჩანაწერები (`example-*.md`) შეგიძლია წაშალო.

## ტექსტის ფორმატირება

- `## სათაური` — ქვესათაური
- `**მუქი**` — მუქი ტექსტი
- `- პუნქტი` — სია
- `[ტექსტი](https://...)` — ბმული

## გაშვება კომპიუტერზე

```bash
npm install      # ერთხელ
npm run dev      # გახსენი http://localhost:4321
npm run build    # მზა საიტი შეიქმნება საქაღალდეში dist/
```

„ჩემ შესახებ“ გვერდის ტექსტი შეცვალე ფაილში `src/pages/about.astro`.
